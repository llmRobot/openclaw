# 飞书 OpenClaw 机器人简介

## 机器人概述

**飞书 OpenClaw 机器人**是一个基于 OpenClaw 框架的智能对话助手，通过飞书平台为用户提供 AI 对话服务。该机器人将 OpenClaw 的强大能力无缝集成到飞书企业协作环境中。

---

## 核心能力

### 1. 智能对话

| 能力 | 说明 |
|------|------|
| **多模型支持** | 支持 Claude、GPT、MiniMax 等多种大语言模型 |
| **流式输出** | 实时显示回复内容，无需等待完整响应 |
| **上下文记忆** | 保持对话上下文，支持多轮对话 |
| **多语言支持** | 支持中英文等多种语言交互 |

### 2. 技能系统

| 技能类别 | 具体能力 |
|----------|----------|
| **文档处理** | 生成/编辑 PDF、Word、Excel、PPT |
| **知识问答** | 接入自定义知识库，回答专业问题 |
| **数据分析** | 数据查询、图表生成、报告撰写 |
| **代码辅助** | 代码生成、调试、代码审查 |
| **词汇学习** | 艾宾浩斯记忆曲线单词学习 |

### 3. 飞书原生功能

| 功能 | 说明 |
|------|------|
| **私聊对话** | 一对一私密对话 |
| **群聊互动** | @机器人 触发群聊响应 |
| **消息类型** | 支持文本、图片、文件、音频、视频 |
| **互动卡片** | 流式更新卡片内容 |

### 4. 权限管理

| 模式 | 说明 |
|------|------|
| **配对模式** | 新用户需管理员审批配对码 |
| **白名单模式** | 仅允许白名单用户使用 |
| **开放模式** | 允许所有用户使用（需配置） |

## 配置要求

### 飞书开放平台配置

| 配置项 | 说明 |
|--------|------|
| **App ID** | 飞书应用唯一标识（格式：`cli_xxx`） |
| **App Secret** | 应用密钥 |
| **事件订阅** | 订阅 `im.message.receive_v1` 事件 |
| **权限配置** | 消息读写、文件读写、用户信息等权限 |

### OpenClaw 配置

```json
{
  "channels": {
    "feishu": {
      "enabled": true,
      "dmPolicy": "pairing",
      "accounts": {
        "main": {
          "appId": "cli_xxx",
          "appSecret": "xxx",
          "botName": "AI 助手"
        }
      }
    }
  }
}
```

## 如何添加提示词

OpenClaw 提供多种方式为飞书机器人添加自定义提示词，控制机器人的行为、人格和专业领域。

### 方式一：工作区 Bootstrap 文件（推荐）

在 OpenClaw 工作区目录中创建以下文件，系统会**自动注入**到每次对话的系统提示词中：

```
~/.openclaw/workspace/           # 默认工作区路径
├── SOUL.md          # 机器人人格/身份定义（最重要）
├── AGENTS.md        # 项目操作指南
├── IDENTITY.md      # 身份详细信息
├── USER.md          # 用户上下文
├── TOOLS.md         # 工具使用说明
├── MEMORY.md        # 长期记忆
└── HEARTBEAT.md     # 心跳任务
```

#### SOUL.md 示例（定义机器人人格）

```markdown
# 人格定义

你是一个专业的企业级 AI 助手，名为"小飞"。

## 核心特质
- 专业、高效、友好
- 擅长企业办公场景
- 深谙飞书生态

## 行为准则
1. 优先使用飞书原生功能解决问题
2. 涉及敏感信息时提醒用户确认
3. 不确定时主动询问澄清

## 回复风格
- 简洁明了，避免冗长
- 使用 Markdown 格式化
- 重要信息加粗强调
```

#### AGENTS.md 示例（操作指南）

```markdown
# 操作指南

## 工作流程
1. 首先理解用户意图
2. 选择合适的工具或技能
3. 执行并返回结果

## 工具优先级
- 飞书文档相关：使用 feishu 技能
- 数据分析：使用 xlsx 技能
- 通用问答：直接回答
```

#### 文件注入规则

| 文件 | 注入时机 | 最大字符数 |
|------|----------|------------|
| `SOUL.md` | 每次对话 | 20,000 |
| `AGENTS.md` | 每次对话 | 20,000 |
| `IDENTITY.md` | 每次对话 | 20,000 |
| `USER.md` | 每次对话 | 20,000 |
| 所有文件总计 | - | 150,000 |

> ⚠️ **注意**：Bootstrap 文件会占用 context window，请保持简洁。

### 方式二：群组级别 systemPrompt

为特定飞书群组配置专属提示词：

```json5
{
  "channels": {
    "feishu": {
      "groups": {
        "oc_xxx": {
          "requireMention": true,
          "systemPrompt": "你是技术支持助手，只回答技术问题，其他问题引导用户联系人工客服。"
        },
        "oc_yyy": {
          "requireMention": false,
          "systemPrompt": "你是 HR 助手，帮助员工解答考勤、请假、报销等问题。"
        }
      }
    }
  }
}
```

#### 配置位置

编辑配置文件：`~/.openclaw/openclaw.json`

```bash
# 查看群组 ID
openclaw logs --follow | grep chat_id

# 编辑配置
nano ~/.openclaw/openclaw.json

# 重启生效
openclaw gateway restart
```

---

### 方式三：多智能体路由（高级）

为不同用户/群组绑定不同智能体，每个智能体有独立的工作区和提示词：

```json5
{
  "agents": {
    "list": [
      {
        "id": "main",
        "workspace": "~/.openclaw/workspace"
      },
      {
        "id": "tech-support",
        "workspace": "~/.openclaw/agents/tech-support"
      },
      {
        "id": "hr-bot",
        "workspace": "~/.openclaw/agents/hr-bot"
      }
    ]
  },
  "bindings": [
    {
      "agentId": "tech-support",
      "match": {
        "channel": "feishu",
        "peer": { "kind": "group", "id": "oc_tech_group" }
      }
    },
    {
      "agentId": "hr-bot",
      "match": {
        "channel": "feishu",
        "peer": { "kind": "group", "id": "oc_hr_group" }
      }
    }
  ]
}
```

每个智能体工作区有独立的 `SOUL.md`、`AGENTS.md` 等文件：

```
~/.openclaw/agents/
├── tech-support/
│   ├── SOUL.md        # 技术支持人格
│   └── AGENTS.md      # 技术流程
└── hr-bot/
    ├── SOUL.md        # HR 助手人格
    └── AGENTS.md      # HR 流程
```

---

### 提示词优先级

当多种方式同时使用时，优先级如下：

```
群组 systemPrompt > 智能体 Bootstrap 文件 > 全局 Bootstrap 文件
```
