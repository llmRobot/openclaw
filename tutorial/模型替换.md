## 配置步骤

### 1. 添加 Provider 配置

在 `models.providers` 中添加新的提供商：

```json
{
  "models": {
    "mode": "merge",
    "providers": {
      "scnet": {
        "baseUrl": "https://api.scnet.cn/api/llm/v1",
        "api": "openai-completions",
        "apiKey": "sk-Mzc1LTExODMwMzk0NDc4LTE3NzM0NTEwMjU2MzU=",
        "models": [
          {
            "id": "MiniMax-M2.5",
            "name": "MiniMax M2.5",
            "reasoning": false,
            "input": ["text"],
            "cost": {
              "input": 0,
              "output": 0,
              "cacheRead": 0,
              "cacheWrite": 0
            },
            "contextWindow": 128000,
            "maxTokens": 4096
          }
        ]
      }
    }
  }
}
```

### 2. 设置为默认模型

在 `agents.defaults` 中设置主模型：

```json
{
  "agents": {
    "defaults": {
      "model": {
        "primary": "scnet/MiniMax-M2.5"
      },
      "models": {
        "scnet/MiniMax-M2.5": {
          "alias": "MiniMax"
        }
      }
    }
  }
}
```

### 3. 重启 Gateway

配置修改后需要重启 Gateway 生效：

```bash
cd /home/robot/agi/openclaw
docker compose restart openclaw-gateway
```

## 配置字段说明

### Provider 字段

| 字段 | 说明 |
|------|------|
| `baseUrl` | API 基础地址 |
| `api` | API 协议类型，`openai-completions` 表示 OpenAI 兼容格式 |
| `apiKey` | API 密钥 |

### Model 字段

| 字段 | 说明 |
|------|------|
| `id` | 模型标识符，调用时使用 |
| `name` | 模型显示名称 |
| `reasoning` | 是否支持推理模式（o1 类模型） |
| `input` | 支持的输入类型：`text`、`image` |
| `contextWindow` | 上下文窗口大小（tokens） |
| `maxTokens` | 最大输出 tokens |
| `cost` | 成本配置（输入/输出/缓存读写） |

### Agent 字段

| 字段 | 说明 |
|------|------|
| `primary` | 默认使用的主模型，格式：`provider/model-id` |
| `alias` | 模型别名，便于显示 |

## 多模型配置

可以同时配置多个模型，按需切换：

```json
{
  "agents": {
    "defaults": {
      "model": {
        "primary": "scnet/MiniMax-M2.5"
      },
      "models": {
        "scnet/MiniMax-M2.5": {
          "alias": "MiniMax"
        },
        "pucode/claude-opus-4-6": {
          "alias": "Claude"
        }
      }
    }
  }
}
```

## 常见问题

### Q: 配置不生效？

检查：
1. JSON 格式是否正确
2. Gateway 是否已重启
3. API Key 是否有效

### Q: 如何切换回原模型？

修改 `agents.defaults.model.primary` 为原模型即可：

```json
{
  "primary": "pucode/claude-opus-4-6"
}
```

### Q: API 兼容性？

MiniMax M2.5 使用 OpenAI 兼容 API 格式（`openai-completions`），可直接对接。
