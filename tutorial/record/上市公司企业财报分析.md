## 完善后的财报分析技能

### 一、核心分析维度与指标体系

#### 1. 每股指标（基础估值）
| 指标 | 有利信号 | 不利信号 | 潜在风险点 |
|------|---------|---------|-----------|
| **摊薄每股收益(EPS)** | 持续增长，>0.5元 | 连续下滑或<0.1元 | 业绩变脸、一次性收益粉饰 |
| **每股净资产(BPS)** | 稳定增长，>5元 | 持续下降或<1元 | 资产减值、亏损侵蚀 |
| **每股经营性现金流** | >EPS，持续为正 | 长期为负或远低于EPS | 利润造假、回款困难 |
| **每股未分配利润** | 累积充裕 | 为负或大幅减少 | 历史亏损、分红能力弱 |

#### 2. 盈利能力（核心竞争力）
| 指标 | 有利信号 | 不利信号 | 潜在风险点 |
|------|---------|---------|-----------|
| **净资产收益率(ROE)** | >15%，持续稳定 | <8%或连续下滑 | 资本效率低下、行业衰退 |
| **销售毛利率** | 高于行业平均，稳定 | 大幅波动或低于同行 | 成本失控、价格战、造假 |
| **销售净利率** | >10%，与毛利率匹配 | <5%或背离毛利率 | 费用异常、非经常性损益占比高 |
| **营业利润率** | 核心利润占比高 | 投资收益/补贴占比高 | 主业空心化、利润操纵 |
| **总资产报酬率(ROA)** | >6% | <3% | 资产周转慢、盈利能力弱 |

#### 3. 偿债能力（财务安全垫）
| 指标 | 有利信号 | 不利信号 | 潜在风险点 |
|------|---------|---------|-----------|
| **资产负债率** | 30%-60%，行业匹配 | >70%或<20%(异常低) | 杠杆过高、隐性负债、存贷双高 |
| **流动比率** | 1.5-2.5 | <1或>5 | 短期偿债压力、资金闲置 |
| **速动比率** | >1 | <0.8 | 存货积压、流动性危机 |
| **利息保障倍数** | >5 | <3 | 偿债压力大、财务费用侵蚀利润 |
| **有息负债率** | 合理可控 | 短期借款激增 | 资金链紧张、借新还旧 |

#### 4. 运营能力（资产效率）
| 指标 | 有利信号 | 不利信号 | 潜在风险点 |
|------|---------|---------|-----------|
| **应收账款周转率** | 高于行业，稳定 | 骤降或远低于同行 | 放宽信用政策、虚构收入、坏账 |
| **存货周转率** | 与业务规模匹配 | 持续下降或异常波动 | 滞销积压、减值风险、成本结转问题 |
| **总资产周转率** | >0.8(制造业) | <0.5 | 资产闲置、扩张低效 |
| **应付账款周转率** | 正常商业信用 | 异常延长 | 占用供应商资金、流动性危机 |

#### 5. 成长能力（发展动能）
| 指标 | 有利信号 | 不利信号 | 潜在风险点 |
|------|---------|---------|-----------|
| **营收增长率** | 10%-30%，与行业同步 | >50%或<0 | 虚增收入、行业衰退、市场饱和 |
| **净利润增长率** | 与营收增长匹配 | 远高于营收增长 | 成本操纵、非经常性损益 |
| **扣非净利润增长率** | 稳定增长 | 大幅波动或负增长 | 主业盈利能力差、依赖补贴 |

### 二、财务造假与异常风险识别体系

基于"五维度"财务舞弊识别模型和学术研究，新增以下**风险预警指标**：

#### 6. 现金流质量指标（防造假核心）

| 指标 | 计算公式 | 风险阈值 | 风险含义 |
|------|---------|---------|---------|
| **净现比** | 经营现金流净额/净利润 | <0.7(10年均值) | 利润含金量低，可能虚增 |
| **收现比** | 销售商品现金流/营业收入 | <0.8 | 收入回款差，可能虚构 |
| **经营现金流/营收** | 经营现金流净额/营业收入 | <5% | 主业造血能力弱 |
| **自由现金流** | 经营现金流-资本支出 | 长期为负 | 持续烧钱，依赖融资 |

**马氏定律**：长期(10年)净现比低于0.7，可能存在利润造假；低于0.5则基本可判定造假。

#### 7. 资产负债表异常信号（财务造假恒等式）

根据财务造假"流程"：虚增利润 → 虚增资产/虚减负债

| 异常信号 | 识别方法 | 潜在风险 |
|---------|---------|---------|
| **应收账款异常** | 增速>营收增速，周转率骤降 | 虚构收入、关联方占款 |
| **存货异常** | 增速>营收增速，周转率下降 | 滞销积压、成本结转操纵 |
| **其他应收款占比高** | >总资产5%或激增 | 资金占用、关联方拆借 |
| **预付账款异常** | 大额长期挂账，关联方 | 资金体外循环、虚假采购 |
| **在建工程/固定资产异常** | 长期不转固或增速过快 | 资本化操纵、虚增资产 |
| **商誉占比高** | >净资产30% | 并购泡沫、减值风险 |
| **货币资金存贷双高** | 大额存款+大额借款 | 资金受限、虚假存款 |

#### 8. 利润表异常信号

| 异常信号 | 识别方法 | 潜在风险 |
|---------|---------|---------|
| **毛利率异常** | 显著高于同行或大幅波动 | 成本虚减、收入虚增 |
| **收入成本不匹配** | 营收增50%但成本仅增5% | 虚增收入、隐匿成本 |
| **非经常性损益占比高** | >净利润30% | 主业盈利能力差 |
| **所得税率异常** | 实际税率远低于25% | 利润虚假、税收调节 |
| **Q4收入占比过高** | 单季>全年40% | 年底冲业绩、提前确认 |

#### 9. 关联交易与治理风险

| 风险信号 | 数据来源 | 风险含义 |
|---------|---------|---------|
| **关联交易占比高** | 年报附注 | 利益输送、虚增收入 |
| **隐性关联方** | 工商信息穿透 | 关联交易非关联化 |
| **大股东资金占用** | 其他应收款、问询函 | 侵占上市公司利益 |
| **违规担保** | 公告、审计意见 | 或有负债、连带责任 |
| **高管频繁变动** | 公告 | 内部治理问题、财务总监离职 |
| **审计机构频繁变更** | 公告 | 审计意见分歧、购买审计意见 |

#### 10. 审计与监管信号

| 信号类型 | 具体表现 | 风险等级 |
|---------|---------|---------|
| **审计意见类型** | 标准无保留意见 | 正常 |
| | 带强调事项段 | 中危：持续经营存疑 |
| | 保留/否定/无法表示意见 | 高危：财务真实性存疑 |
| **内控审计意见** | 否定/无法表示意见 | 高危：财务报告不可靠 |
| **监管问询函** | 频繁收到交易所问询 | 中危：信息披露问题 |
| **立案调查** | 证监会调查通知 | 高危：涉嫌违法违规 |
| **行政处罚** | 证监会处罚决定 | 高危：已确认违规 |

# 年报财务分析技能

## 概述

获取A股上市公司财务报表数据，支持：
- **每股指标**: 每股收益、每股净资产、每股现金流等
- **盈利能力**: ROE、毛利率、净利率、营业利润率
- **偿债能力**: 资产负债率、流动比率、速动比率、有息负债率
- **运营能力**: 存货周转率、应收账款周转率、总资产周转率
- **成长能力**: 营收增长率、净利润增长率、扣非净利润增长率
- **现金流质量**: 净现比、收现比、自由现金流
- **风险预警**: 财务造假信号、关联交易风险、审计意见异常

## 快速开始

### 单股深度分析

```bash
# 获取完整财务分析（含风险预警）
python3 {baseDir}/scripts/analyze.py 000026

# 指定报告期数量
python3 {baseDir}/scripts/analyze.py 000026 --periods 6

# JSON格式输出
python3 {baseDir}/scripts/analyze.py 000026 --json

# 仅获取关键指标
python3 {baseDir}/scripts/analyze.py 000026 --key-metrics

# 生成风险预警报告
python3 {baseDir}/scripts/analyze.py 000026 --risk-report
```

### 多股对比分析

```bash
# 对比多只股票
python3 {baseDir}/scripts/analyze.py 000026 002916 600519 --compare

# 风险筛查模式
python3 {baseDir}/scripts/analyze.py 000026 002916 600519 --risk-screening
```

### 导出报告

```bash
# 导出Markdown报告
python3 {baseDir}/scripts/analyze.py 000026 --output report.md

# 导出JSON数据
python3 {baseDir}/scripts/analyze.py 000026 --output data.json --format json

# 导出风险预警报告
python3 {baseDir}/scripts/analyze.py 000026 --output risk.md --risk-report
```

## 财务指标说明

### 每股指标
- **每股收益(EPS)**: 净利润/总股本，反映每股盈利能力
- **每股净资产(BPS)**: 净资产/总股本，反映每股账面价值
- **每股经营性现金流**: 经营现金流/总股本，反映现金创造能力
- **每股未分配利润**: 累积未分配利润/总股本，反映分红潜力

### 盈利能力
- **净资产收益率(ROE)**: 净利润/净资产，核心盈利指标，>15%优秀
- **销售毛利率**: (营收-成本)/营收，产品盈利空间
- **销售净利率**: 净利润/营收，最终盈利效率
- **营业利润率**: 营业利润/营收，反映核心主业盈利能力

### 偿债能力
- **资产负债率**: 总负债/总资产，>70%高风险
- **流动比率**: 流动资产/流动负债，1.5-2.5为健康
- **速动比率**: (流动资产-存货)/流动负债，>1为安全
- **有息负债率**: 有息负债/总资产，反映真实债务压力

### 运营能力
- **应收账款周转率**: 营收/平均应收账款，越高回款越快
- **存货周转率**: 营业成本/平均存货，越高库存管理越好
- **总资产周转率**: 营收/平均总资产，反映资产利用效率

### 成长能力
- **营收增长率**: 同比营收增长，反映市场拓展能力
- **净利润增长率**: 同比利润增长，反映盈利增长
- **扣非净利润增长率**: 扣除非经常性损益后的利润增长，反映主业真实增长

### 现金流质量（防造假核心）
- **净现比**: 经营现金流净额/净利润，长期<0.7预警
- **收现比**: 销售商品现金流/营业收入，<0.8预警
- **自由现金流**: 经营现金流-资本支出，长期为负预警资金链

### 风险预警指标
- **应收账款异常**: 增速>营收增速且周转率下降
- **存货异常**: 增速>营收增速且周转率下降
- **其他应收款占比**: >总资产5%预警资金占用
- **预付账款异常**: 大额长期挂账，特别是关联方
- **毛利率异常**: 显著高于同行或大幅波动
- **关联交易占比**: >营收30%需警惕利益输送
