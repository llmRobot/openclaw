# 年报财务分析技能

## 概述

获取A股上市公司财务报表数据，支持：
- **每股指标**: 每股收益、每股净资产、每股现金流等
- **盈利能力**: ROE、毛利率、净利率、营业利润率
- **偿债能力**: 资产负债率、流动比率、速动比率、有息负债率
- **运营能力**: 存货周转率、应收账款周转率、总资产周转率
- **成长能力**: 营收增长率、净利润增长率、扣非净利润增长率
- **现金流质量**: 净现比、收现比、自由现金流
- **风险预警**: 财务健康度评分、风险信号识别

## 财务指标体系

### 一、每股指标（基础估值）

| 指标 | 有利信号 | 不利信号 | 潜在风险点 |
|------|---------|---------|-----------|
| **摊薄每股收益(EPS)** | 持续增长，>0.5元 | 连续下滑或<0.1元 | 业绩变脸、一次性收益粉饰 |
| **每股净资产(BPS)** | 稳定增长，>5元 | 持续下降或<1元 | 资产减值、亏损侵蚀 |
| **每股经营性现金流** | >EPS，持续为正 | 长期为负或远低于EPS | 利润造假、回款困难 |
| **每股未分配利润** | 累积充裕 | 为负或大幅减少 | 历史亏损、分红能力弱 |

### 二、盈利能力（核心竞争力）

| 指标 | 有利信号 | 不利信号 | 潜在风险点 |
|------|---------|---------|-----------|
| **净资产收益率(ROE)** | >15%，持续稳定 | <8%或连续下滑 | 资本效率低下、行业衰退 |
| **销售毛利率** | 高于行业平均，稳定 | 大幅波动或低于同行 | 成本失控、价格战、造假 |
| **销售净利率** | >10%，与毛利率匹配 | <5%或背离毛利率 | 费用异常、非经常性损益占比高 |
| **营业利润率** | 核心利润占比高 | 投资收益/补贴占比高 | 主业空心化、利润操纵 |

### 三、偿债能力（财务安全垫）

| 指标 | 有利信号 | 不利信号 | 潜在风险点 |
|------|---------|---------|-----------|
| **资产负债率** | 30%-60% | >70%或<20% | 杠杆过高、隐性负债 |
| **流动比率** | 1.5-2.5 | <1或>5 | 短期偿债压力、资金闲置 |
| **速动比率** | >1 | <0.8 | 存货积压、流动性危机 |
| **利息保障倍数** | >5 | <3 | 偿债压力大 |

### 四、运营能力（资产效率）

| 指标 | 有利信号 | 不利信号 | 潜在风险点 |
|------|---------|---------|-----------|
| **应收账款周转率** | 高于行业，稳定 | 骤降或远低于同行 | 放宽信用政策、虚构收入、坏账 |
| **存货周转率** | 与业务规模匹配 | 持续下降或异常波动 | 滞销积压、减值风险 |
| **总资产周转率** | >0.8(制造业) | <0.5 | 资产闲置、扩张低效 |

### 五、成长能力（发展动能）

| 指标 | 有利信号 | 不利信号 | 潜在风险点 |
|------|---------|---------|-----------|
| **营收增长率** | 10%-30% | >50%或<0 | 虚增收入、行业衰退 |
| **净利润增长率** | 与营收增长匹配 | 远高于营收增长 | 成本操纵、非经常性损益 |
| **扣非净利润增长率** | 稳定增长 | 大幅波动或负增长 | 主业盈利能力差 |

### 六、现金流质量（防造假核心）

| 指标 | 计算公式 | 健康阈值 | 风险含义 |
|------|---------|---------|---------|
| **净现比** | 经营现金流/净利润 | >1.0(健康) | <0.7预警，利润含金量低 |
| **收现比** | 销售现金流/营业收入 | >0.9(健康) | <0.8预警，收入回款差 |
| **自由现金流** | 经营现金流-资本支出 | 持续为正 | 长期为负预警资金链 |

**马氏定律**：长期(10年)净现比低于0.7，可能存在利润造假；低于0.5则基本可判定造假。

## 财务造假信号识别

### 资产负债表异常信号

| 异常信号 | 识别方法 | 潜在风险 |
|---------|---------|---------|
| **应收账款异常** | 增速>营收增速，周转率骤降 | 虚构收入、关联方占款 |
| **存货异常** | 增速>营收增速，周转率下降 | 滞销积压、成本结转操纵 |
| **其他应收款占比高** | >总资产5%或激增 | 资金占用、关联方拆借 |
| **预付账款异常** | 大额长期挂账 | 资金体外循环、虚假采购 |
| **商誉占比高** | >净资产30% | 并购泡沫、减值风险 |
| **货币资金存贷双高** | 大额存款+大额借款 | 资金受限、虚假存款 |

### 利润表异常信号

| 异常信号 | 识别方法 | 潜在风险 |
|---------|---------|---------|
| **毛利率异常** | 显著高于同行或大幅波动 | 成本虚减、收入虚增 |
| **收入成本不匹配** | 营收增50%但成本仅增5% | 虚增收入、隐匿成本 |
| **非经常性损益占比高** | >净利润30% | 主业盈利能力差 |
| **Q4收入占比过高** | 单季>全年40% | 年底冲业绩、提前确认 |

### 审计与监管信号

| 信号类型 | 具体表现 | 风险等级 |
|---------|---------|---------|
| **审计意见** | 标准无保留意见 | 正常 ✅ |
| | 带强调事项段 | 中危 ⚡ |
| | 保留/否定/无法表示意见 | 高危 ⚠️ |
| **监管问询函** | 频繁收到交易所问询 | 中危 |
| **立案调查** | 证监会调查通知 | 高危 |

### API 查询路径（自动多路降级）

脚本按优先级依次尝试以下路径，任意一路成功即停止：

1. **全文搜索 API**（主路径，最可靠）
   - 接口：`/new/fulltextSearch/full?searchkey=公司名+报告类型`
   - 这是浏览器访问巨潮全文搜索页时调用的真实 JSON 接口
   - 返回 `adjunctUrl` 字段直接构建 PDF 直链

2. **个股历史公告 API**（备用路径）
   - 接口：`/new/hisAnnouncement/query`
   - 需要正确的 `orgId`（由股票信息查询自动获取）
   - 支持按报告类别（category）精准过滤

3. **手动下载链接**（自动回退）
   - 当两个 API 均失败时，输出可直接访问的搜索链接

### orgId 自动获取

> **v1 Bug 修复**：旧版本硬编码 `gshb000026`、`sshb000026` 格式的 orgId 是错误的，
> 实际 orgId 是巨潮内部 9 位数字 ID（如 `9900033049`），必须从 API 查询。

v2 通过以下顺序自动获取真实 orgId：
1. 巨潮快速搜索接口 `/new/information/top/search/query`
2. 全文搜索结果中提取
3. 若均失败则仅使用全文搜索路径（不依赖 orgId）

### PDF URL 构建规则

巨潮 PDF 直链格式：
```
http://static.cninfo.com.cn/finalpage/{YYYY-MM-DD}/{announcementId}.PDF
```
- `announcementId`：公告 ID（从 API 返回的 `adjunctUrl` 或 `announcementId` 字段）
- `YYYY-MM-DD`：公告日期（如 `2026-03-28`）

优先使用 API 返回的 `adjunctUrl`（完整相对路径），其次自行拼接。

### 手动下载流程（脚本失败时备用）

**方法一：巨潮全文搜索页（最快）**

直接访问以下 URL（替换公司名即可）：
```

https://www.cninfo.com.cn/new/fulltextSearch?notautosubmit=&keyWord=深南电路%20年度报告&searchType=0

# 半年度报告
https://www.cninfo.com.cn/new/fulltextSearch?notautosubmit=&keyWord=飞亚达%20半年度报告&searchType=0
```

在结果页找到目标报告超链接（如「飞亚达：2025年年度报告」）→ 点击进详情页 → 点击「公告下载」。

**方法二：东方财富公告中心**
```
https://data.eastmoney.com/notices/stock/000026/ANNUAL.html    # 飞亚达年报
https://data.eastmoney.com/notices/stock/002916/ANNUAL.html    # 深南电路年报
```

- 深交所：`https://www.szse.cn/disclosure/listed/fixed/index.html`
- 上交所：`https://www.sse.com.cn/assortment/stock/list/info/company/`
