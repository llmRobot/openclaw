# 产业链深度分析技能

## 技能定位

本技能专注于产业链的**结构性分析**，帮助识别行业中的价值分布、竞争壁垒、投资主线和风险因子。当前覆盖两个核心行业：

- **AI 大模型应用行业**（算力层 → 模型层 → 应用层 → 终端用户）
- **PCB 印制电路板行业**（原材料 → 覆铜板/基板 → PCB制造 → 下游电子整机）

其他行业使用通用分析框架。

---

## 分析框架：五大模块

每次完整的产业链分析，应覆盖以下五个模块。根据用户需求可选择重点展开某模块。

### 模块 1：产业链结构图谱

**目标**：绘制行业的上中下游全貌。

输出要求：
1. 用文本图表绘制**产业链结构图**，三层布局：上游→中游→下游，每层列出核心环节和典型企业
2. 标注各环节的**依赖关系**（箭头方向表示价值流/物料流）
3. 识别**关键节点**：卡脖子环节、高集中度环节、技术壁垒最高的环节

文本图谱格式示例：
```
上游（原材料层）
├── 铜箔：诺德股份、龙电华鑫、嘉元科技
├── 覆铜板（CCL）：建滔集团、生益科技、南亚科技
└── 玻纤布：中国巨石、重庆国际复合材料
    ↓
中游（PCB 制造层）
├── 高层板/AI服务器PCB：深南电路、沪电股份、生益电子
├── HDI板/手机PCB：东山精密、鹏鼎控股
└── 封装基板：深南电路、珠海越亚
    ↓
下游（电子整机层）
├── 数据中心/AI服务器：华为、浪潮、戴尔
├── 消费电子：苹果、三星、小米
└── 汽车电子：比亚迪、特斯拉、博世
```

### 模块 2：竞争格局分析

**目标**：理解行业中谁在赢、凭什么赢、格局如何演变。

分析维度：
- **市场集中度**：CR3/CR5、HHI 指数估算或描述性判断
- **竞争壁垒类型**（选最相关的 2-3 个）：
  - 技术壁垒（专利/工艺/算法）
  - 规模效应（固定成本摊薄/网络效应）
  - 客户粘性（认证周期/切换成本/数据飞轮）
  - 资本壁垒（重资产/产能扩张门槛）
  - 资质/牌照壁垒
- **格局演变趋势**：分散→集中 or 寡头→新进入者颠覆？
- **核心玩家分类**：龙头（份额稳固）/ 挑战者 / 利基玩家 / 潜在颠覆者

### 模块 3：价值链与利润分布

**目标**：找到行业中"钱在哪里"。

分析要点：
- 各环节**毛利率水平**（高毛利 >40% / 中毛利 20-40% / 低毛利 <20%）
- **定价权归属**：谁能向上游/下游转嫁成本？
- **资产属性**：轻资产（平台/软件/品牌）vs 重资产（制造/基础设施）
- **研发密度**：R&D 占收入比，技术迭代速度

典型参考数据：
- PCB 行业：铜箔/覆铜板毛利率约 15-25%；高端 PCB（AI 服务器）35-50%；封装基板 20-35%
- AI 应用层：ToB SaaS 毛利率通常 60-80%；推理算力租赁 40-60%；数据标注 15-30%

### 模块 4：驱动因素与风险识别

**目标**：识别行业未来 1-3 年的关键催化剂和潜在风险。

**增长驱动分析**：
- 技术催化（新产品/新工艺/新应用场景）
- 政策催化（补贴/国产替代/产业政策）
- 需求端爆发（终端市场渗透率提升）
- 供给侧变化（产能扩张/退出/整合）

**风险矩阵**（概率 × 影响度）：
- 供应链集中风险（地缘/单一供应商）
- 技术迭代替代风险
- 竞争加剧/价格战风险
- 周期性风险（下行时买还是等？）
- 监管/合规风险

### 模块 5：投资主线与标的筛选框架

**目标**：给出可操作的投资逻辑框架（不构成投资建议）。

**受益节拍分析**：
- 先行受益：需求爆发第一波获益（通常是基础设施/原材料）
- 主线受益：产业链核心价值承载者（制造/集成层）
- 滞后受益：应用层渗透后才体现（终端品牌/内容/服务）

**筛选框架**（三维评估）：
1. 技术/市场卡位：是否处于不可替代的位置？
2. 财务质量：ROE / 现金流 / 研发强度
3. 估值节点：当前处于产业周期的哪个阶段？

**关键跟踪指标清单**：列出该行业需要持续跟踪的 5-8 个核心指标

## 行业专项知识库

### AI 大模型应用行业

#### 产业链结构

```
上游（算力+数据层）
├── 芯片制造：NVIDIA（GPU）、华为（昇腾）、寒武纪、AMD
├── 算力基础设施：IDC数据中心、云计算（AWS/Azure/阿里云/腾讯云）
├── 训练数据：数据标注公司、爬虫/合规数据集
└── 开发框架：PyTorch、TensorFlow、PaddlePaddle

中游（模型+平台层）
├── 基础大模型：OpenAI（GPT）、Anthropic（Claude）、百度（文心）、阿里（通义）、智谱、月之暗面
├── 垂直模型：医疗/法律/金融/代码专用模型
├── 模型推理平台：推理服务 API、模型微调服务
└── AI中间件：向量数据库、RAG框架、Agent框架

下游（应用层）
├── 企业服务：AI客服、代码生成、办公助手（Copilot类）
├── 行业垂直：医疗影像AI、金融风控AI、工业视觉AI
├── 消费级应用：AI搜索、AI教育、AI内容创作
└── 具身智能/机器人：人形机器人、工业机器人控制系统
```

#### 关键指标
- 推理成本（$/百万 token）：衡量算力效率，每年下降约 50%
- 模型基准分数（MMLU/HumanEval/MATH）：技术能力指标
- 企业客户 ARR 增速：商业化进度
- 算力利用率：IDC/云厂商的核心效率指标
- 开发者生态规模：API 调用量、第三方集成数量

#### 竞争格局特点
- **算力层**：高度集中，NVIDIA GPU 占 AI 训练市场 >80%，形成生态锁定
- **模型层**：寡头竞争，但开源模型（Llama/Qwen）持续压缩闭源模型定价权
- **应用层**：高度分散，ToB 行业化应用壁垒来自数据+场景深度整合
- **中国市场特殊性**：算力国产化压力推动华为昇腾、国产 GPU 加速发展

#### 价值分布

| 环节 | 毛利率范围 | 定价权 | 竞争强度 |
|------|-----------|--------|---------|
| GPU芯片 | 60-70% | 极强（NVIDIA垄断） | 低 |
| 云算力租赁 | 40-55% | 中（多云竞争） | 中 |
| 基础模型API | 50-70% | 中（快速降价） | 高 |
| 企业AI应用 | 55-75% | 强（数据+集成壁垒） | 中 |
| 数据标注 | 15-25% | 弱（劳动密集） | 高 |

### PCB 印制电路板行业

#### 产业链结构

```
上游（原材料层）
├── 铜箔：诺德股份、龙电华鑫、嘉元科技（中国主导全球）
├── 覆铜板（CCL）：建滔集团、生益科技、南亚科技（高频材料：罗杰斯）
├── 半固化片/树脂：陶氏化学、昆山雅化
├── 油墨/化学品：太阳油墨、上村工业
└── 玻纤布：中国巨石、重庆国际复合材料

中游（PCB 制造层）
├── 高层板/AI服务器PCB：深南电路、沪电股份、生益电子
├── HDI板/手机PCB：东山精密、鹏鼎控股（全球最大PCB厂）
├── 封装基板（IC Substrate）：深南电路、珠海越亚、南电科技（台湾：欣兴/景硕）
├── 软板（FPC）：东山精密、鹏鼎控股
└── 汽车/工控PCB：依顿电子、奥士康

下游（电子整机层）
├── 数据中心/AI服务器：华为/浪潮/戴尔（PCB是核心BOM）
├── 消费电子：苹果、三星、小米
├── 汽车电子：比亚迪、特斯拉、博世
├── 通信设备：华为、中兴、爱立信
└── 工控/医疗：Siemens、ABB
```

#### 关键指标
- PCB 层数：层数越高，单价越高（4层→18层→高多层→封装基板）
- 毛利率趋势：观察各季度毛利率变化是否跟随产品结构升级
- 在建工程/资本支出：产能扩张节奏，先行指标
- AI 服务器 PCB 订单增速：当前最强驱动力
- 覆铜板价格指数：原材料成本传导

#### 竞争格局特点
- **高度依赖下游景气度**：服务器/手机/汽车任一细分爆发，对应 PCB 企业受益
- **技术门槛分化**：普通多层板竞争激烈；AI 服务器高层板、封装基板壁垒极高
- **中国主导中低端**：全球 PCB 产能约 55% 在中国大陆，但高端（FC-BGA封装基板）仍由台湾和日本主导
- **AI 算力投资是最强催化剂**：2024-2025年 Hyperscaler（微软/谷歌/亚马逊）资本开支爆发，直接拉动高层板/封装基板需求

#### 价值分布

| 环节 | 毛利率范围 | 技术壁垒 | 当前景气度 |
|------|-----------|---------|----------|
| 铜箔 | 12-22% | 低-中 | 一般 |
| 覆铜板（标准） | 15-25% | 中 | 一般 |
| 高频覆铜板 | 35-45% | 高（罗杰斯垄断） | 好 |
| 普通多层PCB | 10-20% | 低 | 竞争激烈 |
| AI服务器高层板 | 30-40% | 高 | 极好 |
| 封装基板（IC Substrate） | 20-35% | 极高 | 好 |
| 汽车PCB | 25-35% | 中高 | 好 |

### 双行业对比格式

当用户要求对比 AI 行业和 PCB 行业时，使用并排对比结构：

| 维度 | AI大模型应用 | PCB行业 |
|------|------------|---------|
| 产业链长度 | 短（3-4层） | 长（5-6层） |
| 主要壁垒 | 算法+数据+生态 | 工艺+客户认证+规模 |
| 景气周期 | 技术驱动，非典型周期 | 下游需求周期明显 |
| 当前阶段 | 成长期（商业化早期） | 成熟期+AI驱动结构升级 |
| 核心风险 | 商业化节奏、监管 | 贸易摩擦、产能过剩 |

## 与年报分析技能联动

本技能可与 `annual-report` 技能联动使用：

1. **产业链定位**：先用本技能分析公司所在产业链位置
2. **财务验证**：用年报分析技能验证公司的财务质量
3. **对比分析**：对比同产业链多家公司的财务指标

联动示例：
```
# 1. 分析 PCB 行业产业链
使用本技能 → 了解深南电路在产业链中的位置

# 2. 获取深南电路年报数据
使用 annual-report 技能 → download_annual_report --symbol 002916 --year 2025
使用 annual-report 技能 → calculate_financial_indicators --symbol 002916 --year 2025

# 3. 综合判断
结合产业链分析 + 财务数据 → 得出投资分析结论
```

## 质量控制要点

1. **数据真实性**：财务数据（毛利率等）需标注数据来源或标注为"估计区间"，避免精确数字误导
2. **时效性声明**：市场数据截至知识截止日，实时数据建议用户通过 Wind/Bloomberg 验证
3. **行业深度**：对 AI/PCB 以外的行业，应明确告知用户当前技能的专项覆盖范围
4. **中立立场**：分析应覆盖多家企业，不偏向单一公司；投资主线框架部分须加免责声明
