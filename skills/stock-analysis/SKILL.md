# 股票持仓分析技能

分析用户持仓股票的技术指标，生成买入/卖出/调仓建议。

## 持仓数据位置

**重要：用户持仓数据保存在 `portfolio.txt` 文件中！**

当用户询问"我的持仓"、"持仓股票"、"分析持仓"等问题时，应该：
1. 首先读取 `~/.openclaw/workspace/skills/stock-analysis/portfolio.txt` 获取持仓数据
2. 然后对持仓中的股票进行分析

## 使用方式

### 方式一：直接分析持仓（推荐）

当用户问"分析我的持仓"时，执行：

```bash
python3 ~/.openclaw/workspace/skills/stock-analysis/scripts/analyze_portfolio.py
```

这会自动读取持仓数据并生成完整分析报告。

### 方式二：手动读取持仓文件

```bash
# 读取持仓文件
cat ~/.openclaw/workspace/skills/stock-analysis/portfolio.txt
```

### 方式三：分析单只股票

```bash
# 使用 stock-data 技能分析单只股票
python3 ~/.openclaw/workspace/skills/stock-data/stock_query.py --type realtime --symbol 09988
python3 ~/.openclaw/workspace/skills/stock-data/stock_query.py --type history --symbol 03690 --days 30
```

## 分析指标

| 指标 | 说明 |
|------|------|
| MA5/10/20 | 5/10/20日均线 |
| RSI | 相对强弱指标 |
| 涨跌幅 | 当日涨跌幅 |
| 成交量 | 成交量变化 |

## 交易信号规则

| 信号 | 条件 |
|------|------|
| 📈 买入 | 均线多头排列且价格在MA5上方 |
| 📉 卖出 | 均线空头排列且价格在MA5下方 |
| ⚠️ 卖出 | RSI > 75 (超买) |
| ⚠️ 买入 | RSI < 25 (超卖) |
| 💤 持有 | 震荡整理 |

## 注意事项

- 分析结果仅供参考，不构成投资建议
- 股市有风险，投资需谨慎
- 用户询问持仓时，务必先读取 portfolio.txt 获取持仓信息
